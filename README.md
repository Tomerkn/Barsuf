# מערכת Barsuf - פלטפורמה לניהול פרויקטים ומכרזים

מערכת Barsuf היא פלטפורמה אחודה לניהול פרויקטים, פיקוח הנדסי, בקרה תקציבית וניתוח מכרזים חכם מבוסס בינה מלאכותית. המערכת מאפשרת למנהלי פרויקטים ולצוותים בשטח לנהל את כל היבטי הבנייה והביצוע תחת ממשק אחד מהיר ומאובטח.

## מודולים מרכזיים במערכת

1. **ניהול מכרזים חכם (ברבור)**: מנגנון ניתוח מתקדם המשלב עיבוד דו-שלבי לקבלת תובנות מיידיות ממסמכי מכרז בתוך שניות ספורות (כולל חילוץ כתב כמויות ראשוני ומחשבון מחיר מטרה דינמי מבוסס סליידרים), ולאחר מכן ביצוע ניתוח עומק והפקת הצעות מחיר מפורטות.
2. **ניהול סטאטוסים (Workflow)**: ניהול משפך עסקי מבוסס 11 סטטוסים מדויקים (פנייה חדשה, תוכניות הועלו, נשלח לקבלני משנה, ממתין להצעות, הצעות התקבלו, בתהליך תמחור, הצעת מחיר מוכנה, נשלחה ללקוח, ממתין לתשובת לקוח, זכייה, הפסד). התהליך מקיף את המעבר הטבעי משלב מכרז לשלב פרויקט ביצוע.
3. **אינטגרציה וסנכרון דו-כיווני מול Monday.com**: המערכת מאפשרת סנכרון בזמן אמת של כל לוחות המכרזים, הקבלנים וסטטוס ההתקדמות מול מערכת Monday.com בעזרת Webhooks וסנכרוני API (ייצוא למאנדיי, קליטת עדכונים ממאנדיי והטמעת iFrames).
4. **ניהול לוחות זמנים (גאנט)**: למעקב אחר שלבי הביצוע והמשימות בפרויקט.
5. **בקרה תקציבית ופיננסית**: מודולים מובנים לניהול תקציב היעד, רישום הוצאות בפועל, רישום הכנסות וניהול תשלומים לקבלנים.
6. **ניהול קבלני משנה**: רישום ועריכה של קבלני משנה והתמחויותיהם, תוך סנכרון מלא ללוח "ניהול קבלני משנה" במאנדיי.
7. **יומני עבודה יומיים**: כלי לדיווח יומיומי של מנהלי העבודה בשטח כולל תיאור ביצוע, הערכות מפקח ורישום תקלות.
8. **שנת בדק**: ניהול קריאות שירות, תקלות בתקופת הבדק ומעקב אחר סטטוס הטיפול מול דיירים וקבלנים.

## הטכנולוגיות שלנו (במה משתמשים פה?)

המערכת רצה על סטק טכנולוגי פשוט ויעיל שחוסך עלויות שרת ומאפשר מהירות תגובה אפסית:

* **צד לקוח (Frontend)**:
  * **React 19 & Vite** - עבודה חלקה ומהירה מול הדפדפן (SPA).
  * **Tailwind CSS v4** - עיצוב נקי ורספונסיבי כולל תצוגה מותאמת למובייל.
  * **Recharts** - גרפים ואנליטיקה פיננסית בזמן אמת.
  * **React Router v7 & Draggable** - ניווט מהיר בין העמודים והבוט הצף של ברבור.

* **צד שרת ואחסון (Backend & DB)**:
  * **Node.js & Express v5** - שרת ה-API המרכזי שכולל קליטת Webhooks ממאנדיי.
  * **SQLite (Better-SQLite3)** - בסיס נתונים מקומי ומהיר במיוחד (במצב WAL) שחוסך שרת DB יקר.
  * **Multer & PDF-Parse** - קליטת קבצים מאובטחת וחילוץ טקסט גולמי מתוך קבצי PDF.
  * **Google Cloud Storage (GCS)** - אחסון בענן של קבצי המקור וגיבוי אוטומטי של בסיס הנתונים משרת ה-Node.

* **בינה מלאכותית (AI & RAG Core)**:
  * **Claude 3.5 & Gemini 2.5** - קלאוד משמש לניתוח עומק של המכרזים, וג'מיני משמש לבוט השאלות-תשובות וקריאת קבלות (RAG).

* **אוטומציה ופריסה (CI/CD)**:
  * **Docker / Google Cloud Run** - שרת Serverless שמארח את האפליקציה בענן.
  * **Git / Github** - פריסה אוטומטית למערכות CI/CD (`npm run auto-deploy`).

## איך מפעילים את הפרויקט מקומית

1. **התקנת תלויות**:
   מריצים בתיקייה הראשית:
   `npm install`

2. **קובץ הגדרות סביבה (.env)**:
   יש ליצור קובץ `.env` בתיקיית השרת או בתיקייה הראשית ולהגדיר את הפרמטרים הבאים:
   * `PORT`: פורט להרצת השרת (ברירת מחדל 8080).
   * `ANTHROPIC_API_KEY`: מפתח ה-API של Anthropic.
   * `GEMINI_API_KEY`: מפתח ה-API של Google.

3. **הרצה במצב פיתוח**:
   מריצים מהתיקייה הראשית:
   `npm run dev`
   הפקודה תפעיל במקביל את שרת ה-API ואת ממשק ה-Vite של צד הלקוח.

4. **בנייה לשרת ייצור**:
   לצורך קימפול ואיחוד הקבצים:
   `npm run build`
   הקבצים המוכנים יישמרו בתיקיית `dist` ויוגשו סטטית על ידי שרת ה-Express.
